Any comparison with NULL, including `NULL = NULL`, is **unknown**, and WHERE keeps only rows that are true. Test with `IS NULL`.

<TruthTable client:visible />

NOT IN builds a chain of ANDs, one per value in the list. One NULL in the list makes the whole chain unknown:

<NotInTrap client:visible />

Outer joins create NULLs, and aggregates skip them. `count(*)` counts rows, `count(col)` counts non-NULL values, and `sum` over nothing but NULLs is NULL:
